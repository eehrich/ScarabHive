Authentication Not Enabled

User management requires multi-user authentication to be enabled in the system configuration.

To enable user management:

  1. Edit config/config.yaml
  2. Set auth.enabled: true
  3. Configure a secure auth.secret_key
  4. Restart the API server
# config/config.yaml
auth:
  enabled: true
  secret_key: "your-secure-key-here-min-32-chars"
  algorithm: "HS256"
  access_token_expire_minutes: 30
